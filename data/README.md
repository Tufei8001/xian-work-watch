# 数据目录结构

```
data/
├── README.md          ← 本文件
└── xian/
    ├── all.md         ← 西安主数据文件（所有记录）
    ├── img/           ← 证据截图（命名规则见下）
    └── archives/      ← 争议/已删除条目的归档
```

## 截图命名规则

```
{公司简称}-{编号}.{png|jpg}
例：huawei-01.png, xiaomi-evidence-02.jpg
```

## 数据格式规范

每条记录遵守：

```
[公司名] | [所在区] | [标签] | [曝光年月] | [描述] | [证据1] [证据2]
```

- `标签`：从 README.md 不良类型中选择
- `曝光年月`：格式 `YYYY-MM`
- `描述`：客观事实，限 100 字内。禁止情绪化表达
- `证据`：文件名或 URL，空格分隔

## 归档

被 PR 要求删除的条目不直接删除，移入 `archives/` 保留 Git 历史。
